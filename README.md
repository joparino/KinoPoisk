# Shelve

Shelve — учебный проект личной медиатеки на Kotlin Multiplatform и Compose
Multiplatform. Здесь постепенно появятся коллекция произведений, статусы,
прогресс просмотра и чтения, оценки и возможность посмотреть медиатеку другого человека.

Проект продолжает историю Dart и Flutter,
начатой в декабре 2021 года. Предыдущая реализация сохранена в ветке
`archive/flutter`, разработка Kotlin версии идет в `dev`
